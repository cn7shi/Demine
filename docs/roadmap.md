# 项目路线与验收

## 产品目标

为有一定编程基础、希望积累工程经验的开发者提供一个本地伴随工具：接入后自动积累 Agent 执行中的尝试与反馈，让人按需展开理解。对话折叠不删除已有证据；不依赖 Agent 记得主动上报。

## M0：接入验证

- 指定项目与 Codex 来源目录，自动识别会话。
- 列清支持的事件、不可观察信息与实测版本。
- 对照本地记录验证事件类型与调用关系；不将真实对话提交到仓库。

## M1：可持续记录与回放（本次范围）

- 自动发现新会话及现有会话的新增内容。
- SQLite 持久化事件、来源和读取进度；重启续读不重复。
- 半行等待、坏行可见、未知事件保留、来源重写保留旧代次。
- 本地网页的会话列表、时间线、筛选、分页、内容折叠和原始证据。
- 真实浏览器验证自动更新、迟到结果、断线状态和移动布局。

## M2：问题与尝试组织

- 在固定的一组脱敏样例上确定“问题—尝试—观察—判断修正—验证”的提取契约。
- 每轮结束或用户请求时分析新增片段，不对每条事件调用模型。
- 推测与观察分开；所有结论链接证据。分析失败不影响采集。
- 处理跨回合问题、未解决问题、没有有价值经验的普通任务。

## M3：人的经验与 MCP

- 用户笔记、纠错、收藏与导出独立于系统解释，重新分析不覆盖。
- 全库搜索和跨会话引用。
- MCP 提供查看、查询与补充入口；保持采集独立于模型主动调用。
- 首先使用本地网页，随后验证各宿主的 MCP Apps 支持。

## v0.1 公开试用

- 做好安装包、许可证选择、兼容说明和可公开示例。
- 邀请少量目标用户自行接入，观察使用和理解收益。
- 初期暂缓多工具全面支持、云同步、团队功能、全局知识图谱、课程和能力评分。

后续任务优先级：真实使用中记录遗漏/误归并 > 阅读与定位负担 > 经验解释质量 > 入口数量。
